# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues in `mochaccin/mochafolio` managed with the `gh` CLI.

## Consumer rules

- Search and list issues with `gh issue list`.
- View issue details with `gh issue view <id>`.
- Create issues with `gh issue create --title "<title>" --body "<body>"`.
- Comment on issues with `gh issue comment <id> --body "<body>"`.
- Close or edit issues with `gh issue status` / `gh issue edit`.
