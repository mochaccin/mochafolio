# Domain docs

This repo uses a single-context domain documentation layout.

## Layout

- `GLOSSARY.md` at the repo root defines core domain terms and concepts.
- `docs/adr/` contains Architectural Decision Records (ADRs).

## Consumer rules

- Read `GLOSSARY.md` before making domain model changes.
- Check `docs/adr/` for relevant architectural decisions before making major structural changes.
- Create new ADRs in `docs/adr/` when making significant architectural choices.
